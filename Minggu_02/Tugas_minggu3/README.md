## Deskripsi

Aplikasi ini merupakan aplikasi **My Profile App** yang dibuat menggunakan **Kotlin dan Jetpack Compose/Compose Multiplatform**. Aplikasi menampilkan informasi profil pribadi seperti nama, NIM, program studi, deskripsi singkat, serta informasi kontak.

Aplikasi juga menggunakan beberapa **Composable Function** yang dibuat secara terpisah agar kode lebih rapi dan dapat digunakan kembali.

## Fitur Aplikasi

Aplikasi memiliki beberapa fitur utama:

1. **Profile Header**
   - Menampilkan foto profil berbentuk lingkaran.
   - Menampilkan nama.
   - Menampilkan NIM.
   - Menampilkan program studi.

2. **Tentang Saya**
   - Menampilkan deskripsi singkat mengenai profil pengguna.

3. **Informasi Kontak**
   - Menampilkan email.
   - Menampilkan nomor telepon.
   - Menampilkan lokasi.

4. **Hide/Show Contact**
   - Tombol digunakan untuk menyembunyikan atau menampilkan informasi kontak.
   - Perubahan tampilan menggunakan animasi.
